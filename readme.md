Apresentação

A Trilhas Hortifruti é uma loja fictícia criada para simular a compra de frutas. O projeto permite escolher a quantidade de cada produto, calcular o valor da compra e aplicar um desconto quando o valor mínimo é atingido.

Produtos e preços

- Maçã: R$ 4,00 por unidade
- Banana: R$ 2,00 por unidade
- Mamão: R$ 7,00 por unidade

Compras a partir de R$ 30,00 recebem 10% de desconto.

Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

Como executar

1. Abra o arquivo "index.html" em um navegador.
2. Clique no botão "Simular minha compra".
3. Informe a quantidade de cada fruta.
4. Confira o resumo e o total da compra.
